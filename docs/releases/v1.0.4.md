# v1.0.4 · 阅读备份与查词收尾

面向中文使用者，在现有中文阅读、查词和收藏功能上完善数据保存与查询体验。

## 新增功能

- **阅读数据备份与恢复**：历史页可导出 JSON，包含历史、收藏、复习进度和卡片外观。恢复前预览，默认合并；替换需再次确认。备份不包含 API Key、服务商配置或翻译缓存。CSV 仍用于表格导出，不能恢复数据。
- **查询取消与重试**：首次查询立即显示卡片；连续查词保留卡片尺寸和已有内容。加载时可取消，失败或取消后可重试；关闭卡片后，晚到的结果不会重新打开它。
- **检查新版**：工具栏可手动检查本仓库的最新正式发布。首次需授权 GitHub API 可选域名；授权后打开工具栏最多每 24 小时检查一次。提供发布页入口，更新仍需手动安装。

## 修复与调整

- 网络失败时保留同批次中已有的缓存或固定术语译文，并提示未完成部分。
- 主服务正常时不再受无效备用配置影响；保存设置前检查已启用的备用服务配置。
- 缓存按服务商、模型与翻译风格隔离，避免混用旧的风格结果。首次查询可能需要重新联网。
- 对齐主服务、备用服务与内容脚本的等待期限，减少提前超时。
- 收藏状态通过后台串行更新，并同步到其他打开的卡片。
- 复习只包含到期或未复习的收藏；记住后延长间隔，稍后复习设为次日。
- 滚动或调整窗口时收起旧位置的选词放大镜；补全常见词性缩写。

## 安装与更新

1. 下载本发布的 `CS2-HLTV-Chinese-Reader-v1.0.4.zip`，解压到固定目录。
2. 首次安装：打开 Chrome/Edge 扩展管理页，开启开发者模式，选择“加载已解压的扩展程序”，选中直接包含 `manifest.json` 的文件夹。不要选择 ZIP 文件。
3. 已安装用户：先在历史页导出阅读备份；将新文件覆盖到原安装目录，点击插件“重新加载”，再刷新 HLTV 页面。保持原路径以保留扩展身份和数据。
4. 服务商配置和 API Key 仍需在设置页保存、授权并测试连接。详细安装步骤、文件夹选择说明和故障处理见仓库中文 README。

## 验证与边界

- 206 项模拟测试通过；类型检查、五个构建输出、JS 语法及 MV3 架构检查通过。12 项反向验证能够捕获对应故障。
