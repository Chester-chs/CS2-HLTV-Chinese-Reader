# v1.0.4 收尾与维护说明

用户于 2026-10-11 确认以下交互契约。发布状态以 `PROGRESS.md` 和实际 GitHub Release 为准。

## 数据备份

- 历史页通过后台既有串行队列执行 `export-backup` / `import-backup`。
- JSON 格式标记为 `cs2-hltv-zh-reader-backup`、格式版本为 `1`，包含导出时间、历史、收藏、复习及外观。
- 外观只包含 `theme`、`cardColor`、`fontScale`。不备份服务商、API Key、缓存或浏览器账号信息。
- 格式、版本、条数、字符串长度、有限时间数值、复习归属及外观枚举先校验；文件上限 32 MB。
- 合并保留当前同名记录和复习状态，包括“没有复习记录”这一状态。容量为历史 50、收藏 100；预览和结果显示超额数量。
- 替换需用户再次确认；仅写阅读数据，不修改服务商。使用一次 `storage.set`，不先清空。替换可修复损坏的当前阅读数据，合并无法读取时停止。
- 恢复退出当前复习会话；成功或失败均同步按钮与列表。JSON 可恢复，CSV 仅为表格导出。

## 查询生命周期

- 初次查词立即建立加载卡片。连续查询保留原卡片及其尺寸；输入草稿、光标和焦点继续按原约定保留。
- 等待期间有“取消查询”，失败/取消后有“重试”。关闭卡片、重新查询会中止前次请求。
- 内容端生成会话 UUID 加序号；后台按发送方 tab/frame/URL 与请求 ID 定位请求。选择查询单独执行，避免中止共享的页面批次。
- 取消从内容端 AbortSignal 经取消消息进入后台，传到主/备用 HTTP fetch。取消后不启动备用服务，也不把晚到结果存入会话缓存。
- 后台响应、内容等待有界；真实服务商是否已收到或计费取决于服务商，取消无法撤回已处理的请求。

## 部分成功

- 成功响应可带 `warning: { code, message, failedIndexes }`；索引基于当前请求、整数且不重复，范围必须合法。
- 后台把未命中项的索引映射回原批次，保留词典与缓存中的可用译文。全失败返回原文与错误。
- 内容端再次映射去重索引到原输入，只缓存成功项；页面显示未完成提示。全批失败也提供失败索引。
- 清会话缓存增加 generation；旧请求不能回填新的缓存世代。
- 新风格缓存命名空间为 style-v1；旧缓存物理保留，但不再复用歧义条目。

## 新版检查

- “检查新版”直接在点击手势中请求可选域名 `https://api.github.com/*`，不新增必需权限；保留 `storage` 作为唯一必需权限。
- 读取 [GitHub 最新发布接口](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)，仅请求此项目公开信息，不带凭据或用户阅读数据。
- 授权后打开工具栏弹窗最多每 24 小时自动检查一次。失败也记录尝试时间，手动检查可立即重试。
- 只接受正式发布的三段数字版本及本仓库精确的 HTTPS 标签链接，按数字比较版本。
- 只提醒并打开发布页面；不自动下载、执行或安装。没有后台定时任务、alarms 或通知权限。

## 验证与后续维护

- `npm test`、`npm run typecheck`、`npm run build`。核心依赖方向检查包含在测试中，修改核心时也需单独运行。
- 每次检查 5 个输出 JS 的语法、后台/内容 IIFE、无裸 import/export、MV3 worker-only、storage-only，以及四个必需文件。
- 新增/修改检查需反向验证。源代码审查与模拟测试不能代替用户真实浏览器试用。
- 打包文件来自 `dist/` 加中文 README、INSTALL、LICENSE 及相应说明；ZIP 根目录直接包含 manifest。
- 更新原安装目录并最后写 manifest，核对包/安装文件哈希；不修改浏览器配置、账号或存储。
- 提交前列出文件清单并获所有者确认，逐个暂存；不提交 dist/raw-capture/node_modules 或密钥。推送后核对 HEAD 与远端 main。
- 牛津官方词库/API/录音接入仍等待授权与凭据；当前为模型词典及官方核对入口。Firefox 和全面 HLTV 页面覆盖仍未完成。
